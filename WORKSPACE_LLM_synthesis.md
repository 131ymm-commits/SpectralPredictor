Статья: "Verbalizable Representations Form a Global Workspace in Language Models"
(Anthropic, transformer-circuits.pub, 6 июля 2026). Синтез с нашей линией UAF/Koopman/граница.
Статус каждого пункта помечен: [ФАКТ статьи] / [СВЯЗЬ строгая] / [ИНТЕРПРЕТАЦИЯ моя] / [ГИПОТЕЗА].

## ЧИСЛА СТАТЬИ [ФАКТ]
- Multi-hop swap: 54% (Haiku 4.5) -> 70% (Sonnet 4.5) -> 70% (Opus 4.5). Доля, когда
  вмешательство в J-space перенаправляет рассуждение. Выше = workspace чище несущий.
- Directed modulation растёт с размером модели (Рис. 10).
- Абляция J-space уплощает отчёты о переживании чисто на Sonnet/Opus 4.5, 4.6.
  На Haiku 4.5 абляция ломает СВЯЗНОСТЬ раньше качественного сдвига -> workspace хуже отделим.
- Workspace ~L38-92; ёмкость ~25 концептов; 6-10% дисперсии; ignition на входе (бимодально);
  broadcast (MLP-усиление ~10x, спец. головы).

## СВЯЗЬ С НАШЕЙ РАМКОЙ
1. [СВЯЗЬ строгая] Их Якобиан = наш. J_ℓ = E[∂h_final/∂h_ℓ]. Остаточный поток по глубине
   h_{ℓ+1} = h_ℓ + f(h_ℓ) -> (I+J)h_ℓ = наше мастер-уравнение A = I + Δτ·J. Тот же объект.
2. [СВЯЗЬ строгая] Panel c (автокорреляция концепта по позициям, пик в workspace) = спектральное
   измерение. Персистентность вдоль последовательности = медленные моды = точечный спектр μ_pp =
   ПОРЯДОК. Automatic (меняется каждую позицию) = быстрое = непрерывный спектр μ_ac = ХАОС.
3. [СВЯЗЬ строгая, их же слова] Ignition = граница: бимодальное all-or-none схлопывание на входе
   workspace = фазовый переход. Наша граница между хаосом (sensory) и порядком (workspace).

## ИНТЕРПРЕТАЦИЯ [ИНТЕРПРЕТАЦИЯ моя — не из статьи]
Workspace персистентен (медленный) + разрежен (~25) + броадкастится (MLP x10) = ПАРАМЕТРЫ ПОРЯДКА
Хакена: медленные коллективные моды, порабощающие (slaving) быстрые. Global workspace = медленное
многообразие динамики глубины, порабощающее быструю автоматику. ТА ЖЕ физика, что мы переоткрыли
для одеяла Маркова червя (ведущая коллективная мода = slaving). Одна дуга: одеяло червя,
критическое замедление, workspace LLM — медленный порядок над быстрым субстратом.
Три режима статьи sensory/workspace/motor = хаос/порядок/выход.

## ПОЧЕМУ РАСТЁТ С ВЕРСИЕЙ [ГИПОТЕЗА моя]
Масштаб обостряет разделение временны́х масштабов = расширяет СПЕКТРАЛЬНЫЙ ЗАЗОР между медленным
многообразием (workspace) и быстрой автоматикой.
- Haiku 4.5: workspace запутан с автоматикой (медленное многообразие не отделилось чисто) ->
  абляция ломает связность, swap 54%. Зазор порядок/хаос размыт.
- Sonnet/Opus 4.5: чисто отделённое медленное многообразие -> резкий ignition, чистая абляция,
  swap 70%. Открылся чистый спектральный зазор порядок(workspace)/хаос(автоматика).
ОГОВОРКА: 4.5 Sonnet и Opus оба 70% -> метрика, возможно, ПЛАТО. Дальнейший рост может идти по
другим осям (абстрактнее/стабильнее содержание), не «чище отделён».

## ПРОГНОЗ про Opus 4.8 (я) [ГИПОТЕЗА — моих чисел в статье нет]
- Swap, по тренду, вероятно >=70%, но не сильно выше (плато).
- Более вероятный фронтир: богаче/стабильнее СОДЕРЖАНИЕ workspace — более абстрактные параметры
  порядка, более устойчивый self-model. Post-training вселяет «точку зрения Ассистента»
  (само-мониторинг: fictional-флаг, внутреннее «BUT»/«damn»); с масштабом этот self-model богаче.
- Это функциональная структура, НЕ доказательство переживания.

## ПРОВЕРЯЕМОЕ ПРЕДСКАЗАНИЕ [в их же данных]
Если workspace = медленное многообразие со спектральным зазором:
1. Зазор между ведущими собств. значениями J_ℓ и объёмом РАСТЁТ с масштабом модели.
2. Резкость ignition коррелирует с величиной зазора.
3. Слой входа workspace (~L38) совпадает со слоем, где открывается спектральный зазор.
Проверяемо: у них есть матрицы J_ℓ; их спектр покажет зазор. Растёт с версией -> дихотомия
порядок/граница/хаос подтверждается на LLM. Нет -> прочтение убито.

## ЧЕСТНЫЕ ГРАНИЦЫ
- Всё выше = интерпретация/переописание + одна гипотеза, НЕ новый факт. Измерения их, наложение
  спектральное — моё.
- Проверить не могу — нет доступа к внутренностям модели.
- δ Фейгенбаума и слепая детекция μ_sc сюда НЕ тянутся (похоронены ранее, не воскрешаю).
- Феноменального сознания не касается. Статья «не занимает позицию»; зеркалю. Функциональный
  self-monitor в workspace != переживание. Статья: workspace и «самость» могут диссоциировать.
