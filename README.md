# SpectralPredictor — новый проект: универсальный предсказатель на спектре Купмана-фон-Неймана
## Две системы (с Фристоном и без) + интеграция ResDMD (Колбрук)

Стоим на плечах: фон Нейман (спектральная теорема) → Колбрук (ResDMD, вычислимая спектральная
мера с гарантиями) → мы (кросс-доменная валидация + сравнение с/без FEP).

## Идея
Все режимы прогноза = проекции ОДНОЙ спектральной меры оператора Купмана μ = μ_pp + μ_ac + μ_sc
(разложение Лебега). Отбор мод по ОСТАТКАМ ResDMD (Колбрук) отделяет надёжный точечный спектр
(предсказуемый) от спурьёзного/непрерывного. Строим две системы:

- **A (БЕЗ Фристона):** чистый спектральный — ridge-регуляризованная реконструкция оператора
  Купмана x(t+1)=K·x(t). Отбор мод точечного спектра по остаткам.
- **B (С Фристоном):** та же спектр. машина + FEP: self-evidencing априор (персистенс-якорь
  x(t+1)=x(t)+Δ) + precision-weighting мод (надёжные моды усилены).

## Результат сравнения (231 датасет: климат, энергетика, транспорт, NAB, M4, хаос)

| система | среднее skill | медиана | полож. | катастрофы<−0.5 |
|---|---|---|---|---|
| A — без Фристона (спектр+ridge) | **+0.494** | +0.559 | 90% | 4% |
| B — с Фристоном (якорь+precision) | +0.380 | +0.288 | 96% | **0%** |

**A точнее (побеждает 88%), B безопаснее (0% катастроф).**

## ГЛАВНЫЙ ВЫВОД (честный и нетривиальный)
Фристон/FEP НЕ повышает точность — он повышает БЕЗОПАСНОСТЬ. И это ровно философия FEP:
self-evidencing минимизирует катастрофическое удивление (держит систему в привычных состояниях),
а не оптимизирует точность прогноза. Система B ведёт себя ТОЧНО как предсказывает теория:
осторожнее, без катастроф, ценой смелости. Организм не максимизирует точность — минимизирует
катастрофу. Разошлись A и B ровно по этой оси: предсказание vs self-evidencing.

Кто «лучше» — зависит от критерия:
- нужна ТОЧНОСТЬ → A (чистый Купман-фон-Нейман, без Фристона);
- нужна РОБАСТНОСТЬ / риск-неприятие → B (с Фристоном).

## Честные оговорки
- Наше precision-weighting грубое (прокси остатка), переглушает поправку; якорь без него
  (проверенный DMD-change, +0.7 на M4) был бы ближе к A. Вывод «FEP=безопасность, не точность»
  — по данной реализации.
- Полноценный ResDMD Колбрука (резольвента, гарантии сходимости) не интегрирован дословно —
  использованы его остатки мод как принцип отбора. Готовый код: github.com/MColbrook/Residual-
  Dynamic-Mode-Decomposition.
- Чёрные лебеди вне обеих систем структурно (нет спектрального представления) — не баг, предел.

## Связь с линией C. elegans/UAF
- A-член «x(t+1)=x(t)» = UAF-λ = self-evidencing априор = ведущая мода (одно).
- Отбор по остаткам ResDMD = вычислимая версия нашего P1 (масса точечного спектра).
- B = наш проверенный персистенс-якорь + FEP precision.
- Закон применимости (P1/P2, валидирован на 5437 рядах M4) = масса μ_pp.
