# Вердикт: три системы + одеяло Маркова как спектральное разложение (2696 датасетов)

## Исправленный результат (убрано переглушение в B)

| система | среднее skill | медиана | полож. | катастрофы<−0.5 |
|---|---|---|---|---|
| A — без Фристона (ridge-спектр) | +0.243 | +0.390 | 85% | 8% |
| **B — Фристон (self-evidencing якорь, БЕЗ переглушения)** | **+0.431** | +0.379 | **97%** | **1%** |
| C — прогноз B + структура одеяла | +0.431 | +0.379 | 97% | 1% |

**ФРИСТОН ПОБЕЖДАЕТ по обоим критериям.** Убрав переглушающее precision-weighting, System B
(чистый self-evidencing персистенс-якорь) обошла A по среднему (+0.43 vs +0.24) И по
безопасности (1% катастроф против 8%). Прежний проигрыш B был артефактом переглушения.
Гипотеза заказчика подтверждена: якорь-без-precision даёт FEP И точность, И робастность.
(Голова-в-голову почти ровно 43/42%, но катастрофы A топят его среднее — FEP их убирает.)

## Одеяло Маркова = спектральное разложение (операционально подтверждено)

System C раскладывает спектр Купмана на три части (гипотеза: = одеяло Маркова):
- **НУТРО (порядок μ_pp): 32%** — предсказуемая автономная динамика = self-evidencing = внутренние состояния.
- **ОДЕЯЛО (граница μ_sc): 11%** — критический интерфейс = blanket = реальный промежуточный слой.
- **СРЕДА (хаос μ_ac): 57%** — нередуцируемая случайность = внешние состояния.

**Ключ: корр(доля НУТРА, точность) = +0.42.** Масса внутреннего спектра предсказывает
применимость — ровно как одеяло: больше защищённого нутра → предсказуемее. Три спектральные
области ведут себя как внутреннее/одеяло/внешнее. **Разделение порядок/граница/хаос = структура
одеяла Маркова**, и формулы взаимодействуют в его рамках: нутро предсказывается, среда
отбрасывается, граница мониторится (EWS).

## Честные оговорки
- **C прогнозирует так же, как B**: структура одеяла — интерпретирующий слой, не отдельный
  предсказатель. Мод-селективная реконструкция (предсказывать только нутром) численно
  неустойчива (W Λ W⁻¹ взрывается для дефективных операторов). Прогноз — стабильный DMD-change,
  разложение — диагностика поверх.
- **Полный ResDMD Колбрука не портирован**: репозиторий MATLAB; формула остатков реализована в
  Python (в диагностике). Строгое выделение μ_sc требует резольвенты Колбрука, не порогов.
- Чёрные лебеди вне всех трёх систем — структурный предел.

## Итог
1. Фристон (правильно реализованный self-evidencing якорь) даёт И точность, И безопасность — B
   бьёт A по среднему и по катастрофам.
2. Order/boundary/chaos — операционально одеяло Маркова: нутро-масса предсказывает применимость
   (r=0.42), граница μ_sc — реальный ~11% слой.
3. Прогноз един (стабильный DMD-change = self-evidencing); одеяло — интерпретирующая структура
   поверх, а не отдельный форкастер.
